# Snake Game 🐍

Juego Snake clásico desarrollado con React + Vite.

## Descripción

Implementación del juego Snake usando React con componentes, props y estado. 
Incluye pantalla de inicio, game over, puntaje y animaciones.

## Instalación y ejecución

```bash
npm install
npm run dev
```

Luego abre http://localhost:5173 en tu navegador.

## Cómo jugar

- Presiona **JUGAR** para iniciar
- Usa las **flechas del teclado** para mover la serpiente
- Come la comida roja para crecer y sumar puntos
- Evita chocar con las paredes o con tu propio cuerpo
- Al morir puedes presionar **JUGAR DE NUEVO**
